# 隐私说明

Research Workbench 是本地优先的单机桌面应用，没有账号、云同步、遥测、广告或行为分析服务。核心记录功能无需联网，不会把科研记录上传到开发者服务器。

## 本机数据

Windows 与 macOS 均使用 Tauri 应用数据目录中的 SQLite 数据库，应用标识为 `com.researchworkbench.desktop`。数据库保存记录、工作区、设置、编辑草稿、回收站和活动历史；设置中的数据管理可查看存储信息。

数据库和备份没有应用层加密。能够访问你的系统账户或备份文件的人可能读取其中内容。文件及文件夹引用保存名称和路径，不复制或上传原文件；导出数据可能暴露本地目录名称。

## 备份与删除

- 每日自动创建数据库快照，保留最近 30 份；快照包含草稿及回收站。备份位于应用数据目录下的 `backups/`。
- 记录删除后进入回收站，保留 30 天；活动历史保留 366 天。历史备份可能继续保存已删除内容，直到相应备份被移除。
- JSON 是明文可移植备份，用于导入导出；它不包含编辑草稿。Markdown、CSV、HTML 导出不含回收站记录。
- 数据迁移前创建备份。旧 Windows 版通过用户导出的 JSON 迁移，新版不删除旧 Electron 数据目录。
- 卸载前先导出所需数据。卸载可能保留数据库和备份；如需完整删除，请先退出应用，再删除数据管理中显示的应用数据目录，以及自行导出的备份。旧版数据目录需另外处理。

自动备份保存在同一设备，不能防止设备损坏或丢失；重要数据应另存到受保护的其他存储介质。

## 网络及系统集成

用户点击「检查更新」时，应用请求 GitHub 的公开 Release API 获取版本信息；下载页和 HTTPS 外链交给默认浏览器。GitHub 及第三方网站按自身隐私政策处理网络请求，不会随请求发送科研记录。

系统通知可能在锁屏或通知中心显示待办信息，可在应用设置及系统设置中关闭。用户主动打开文件引用时由系统默认程序处理，适用该程序自己的数据处理方式。
