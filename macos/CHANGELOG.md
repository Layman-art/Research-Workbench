# 更新日志

## 未发布

### 性能与工程基础

- 固定使用 Node.js 22 与 pnpm 11，统一开发、测试和构建环境。
- 收窄 Zustand 组件订阅，并将筛选与分类计数集中为可测试的纯函数，减少无关状态变更引发的重渲染。
- 中文界面改用 macOS 系统字体，拉丁字体仅打包实际使用的字重；生产构建字体资源由 22,890,552 字节、666 个文件降至 260,216 字节、10 个文件。
- 增加 50 条记录测试夹具、存储隔离测试和 `pnpm size` 构建体积报告。
- 桌面外壳由 Electron 迁移至 Tauri 2，面向 Apple Silicon 构建原生 macOS 应用。
- 数据存储由 localStorage 迁移至带外键约束和事务回滚的 SQLite；磁盘写入成功后才更新界面缓存。
- 增加启动加载/错误恢复界面、浏览器预览适配器以及安全的 HTTPS 外链校验。

### 写作与科研工作流

- 正文支持安全的 GFM Markdown 编辑/预览、纯文本摘要，以及 SQLite 草稿自动保存、恢复和未保存关闭保护。
- 增加纸墨浅色、月夜深色、跟随系统主题，并支持完整/减少/跟随系统动效和中文排版细节。
- 支持 JSON 完整备份，以及 Markdown、CSV、HTML 便携导出；CSV 防公式注入，HTML 清理不安全标签。
- 待办支持日/周/月周期规则，并通过单一数据库事务完成当前项和生成下一项。
- 待办可关联科研项目；项目卡片展示下一步行动，并提供列表/四列看板切换与可访问拖拽。
- 增加轻量文献笔记，包含作者、年份、DOI、HTTPS 链接和阅读状态。
- 月相分布图可点击或用键盘导航到对应记录类型。
- 增加多选批量归档、移动工作区和按精确数量确认删除。
- 到期与过期待办支持 macOS 原生通知、跨重启投递去重、通知点击定位与 Dock 角标。
- 使用 macOS 原生交通灯标题栏和菜单栏托盘；关闭窗口后可从托盘恢复或退出。
- 看板和导出模块按需加载，默认主 JavaScript 包保持在 500 kB 以下。

### macOS 本地发行

- 生成 Apple Silicon arm64 `.app` 与 `.dmg`，使用 ad-hoc 本地签名并通过严格签名及磁盘映像校验。
- 最终生产资源：JavaScript 553,784 字节、CSS 31,278 字节、字体 260,216 字节；`.app` 约 17 MB，`.dmg` 约 6.3 MB。
- 增加安装、升级、备份、数据目录与卸载说明。

## 首个公开发行版 - 2026-08-13

首个公开版本。

### 功能

- 统一管理科研项目、研究方向、待办、日程与通用记录。
- 支持工作区、自定义内容类型、自定义字段、搜索与状态筛选。
- 提供本地 JSON 导入、导出与示例数据恢复。
- 支持 Windows 托盘驻留、开机自启与自定义关闭行为。
