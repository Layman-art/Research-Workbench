# 隐私说明

Research Workbench 是本地优先的单机桌面应用。

## 应用不会主动收集什么

- 没有账号系统。
- 没有遥测、行为分析或广告 SDK。
- 不会把项目、记录、待办或日程上传到开发者服务器。
- 核心记录功能无需联网。

README 徽章、GitHub 下载和用户主动打开的外部链接由浏览器访问，不属于应用内的数据上传。

## 数据存放在哪里

项目、记录、内容类型、工作区和显示名保存在 Electron 的本机存储中；托盘与开机自启偏好保存在同一用户数据目录下的 `app-settings.json`。Windows 上该目录通常位于 `%APPDATA%` 下的 Research Workbench 应用目录。

这些数据没有应用层加密。能够访问你的 Windows 账户或备份文件的人，可能读取其中内容。

## 备份与删除

- 「设置与数据 → 数据管理」可导出或导入明文 JSON 备份。
- JSON 备份可能包含敏感科研信息，请像保护原始记录一样妥善保存。
- 应用目前不提供自动备份或云同步。
- 卸载应用前请先导出所需数据。卸载程序可能保留用户数据；如需完整删除，请退出应用、卸载后再删除 `%APPDATA%` 下对应的 Research Workbench 用户数据目录。

## 网络与外部链接

应用只允许 HTTPS 外部链接交给系统默认浏览器打开。浏览器访问第三方网站时，适用相应网站自己的隐私政策。
