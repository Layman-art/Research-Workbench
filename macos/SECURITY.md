# 安全策略

## 支持范围

安全修复仅面向最新公开版本。请先在 [Releases](https://github.com/Layman-art/Research-Workbench/releases) 中确认版本，并在报告中附上版本号与操作系统信息。

## 报告安全问题

请通过 GitHub 的 [Private vulnerability reporting](https://github.com/Layman-art/Research-Workbench/security/advisories/new) 私下报告漏洞，不要先创建公开 Issue。

报告应尽量包含：

- 受影响版本与环境
- 可重复的操作步骤或最小示例
- 可能造成的影响
- 已尝试的缓解措施（如有）

请勿在报告中包含真实科研数据、账号凭据或其他不必要的个人信息。
