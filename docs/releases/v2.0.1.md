# 科研工作台 v2.0.1

- **日程更清爽**：周历、月历、列表按需切换，同一条日程不再上下重复显示。
- **写笔记更直接**：默认输入普通文字即可，Markdown 排版可选；保存失败时支持另存 TXT。
- **保留简洁总览**：近期日程、到期提醒、最近笔记和项目下一步集中展示。
- **延续 v2 的可靠保存**：草稿恢复、每日备份、回收站、资源优化和跨天自动刷新均保留。

README 已更新为图文介绍，所有展示图片均使用虚构示例数据。

v2.0.0 用户可退出软件后安装新版，数据目录保持不变。旧 Electron Windows 版请先导出 JSON，再在新版「设置与数据」中预览导入；导入前请备份新版已有内容。

下载 Windows x64 `.exe` 或 macOS Apple Silicon `.dmg`。首次安装可能因尚未正式签名或公证而出现系统提示，安装说明见 [README](https://github.com/Layman-art/Research-Workbench#快速开始)。
