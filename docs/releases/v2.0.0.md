# 科研工作台 v2.0.0

这次大版本把 Windows 和 macOS 统一到 Tauri + SQLite，重点解决长笔记保存、数据恢复和常驻体验。

- **保存更可靠**：明确显示保存状态，失败保留内容并可重试，避免重复记录；自动草稿支持恢复未命名笔记，长文可展开编辑。
- **数据有退路**：每日自动备份保留最近 30 份，删除记录进入 30 天回收站，导入前可预览。
- **跨天自动刷新**：午夜、睡眠唤醒和重新切回窗口后更新日期及今天标记。
- **降低日常开销**：优化状态订阅、草稿写入、字体和大列表加载，修复工作区新建及清空已完成的范围。
- **科研工作流补齐**：跨平台 Markdown、搜索、项目看板、循环待办、系统通知、深色主题；新增项目关联、本地文件/文件夹引用、周报/月报 Markdown 导出。

## 升级提醒

**旧 Windows 版请先导出 JSON，再在新版数据管理中预览并导入**；导入替换新版当前数据，旧版数据目录不会被删除。旧 macOS 版沿用原数据目录，迁移前自动备份，仍建议升级前另存 JSON。

下载 Windows x64 `.exe` 或 macOS Apple Silicon `.dmg`。安装包尚未完成正式代码签名及 macOS 公证，系统可能提示安全风险；请只从本仓库下载。文件引用不复制原文件，换机后可能需要重新指定路径。
